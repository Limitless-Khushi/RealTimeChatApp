## Project 2: Real-time Chat (SignalR)
A high-performance real-time messaging application designed using ASP.NET Core SignalR and built on the modern .NET 10.0 architecture. This system utilizes full-duplex WebSockets communication to push instant server-side data synchronization to web clients without requiring continuous HTTP polling or page refreshes.

### Project Scope & Features
* **Bi-directional WebSockets Communication:** Continuous connection persistence handling using lightweight backend SignalR Hub infrastructure routing.
* **Targeted Isolated Channels:** Group structures split messages logically into individual specific developer nodes dynamically.
* **Dynamic Client UI Interface:** Event-driven asynchronous responsive layout updating with instant styling filters applying to system events.
* **Modern Interface Engine:** Built with a dark professional developer dashboard environment frame layout powered by Bootstrap.

### Tech Stack
* **Backend Framework:** ASP.NET Core MVC Core SignalR Platform (.NET 10.0)
* **Programming Language:** C#
* **Frontend Web Stack:** Razor Views, Core JavaScript Client SDK, Bootstrap 5 CSS layout
